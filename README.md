# Waypoint-Minimap
This mod is the waypoint mod by TheThinker and the Minimap mod by Foxydemon88 combined.
# New features:
Waypoints visible on minimap<br>
Waypoints visible through walls (UI)<br>
More minimap info<br>
Multiple optimisation changes<br>
